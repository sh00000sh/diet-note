개인정보처리방침

식단 노트 · 시행일 2026년 10월 30일

식단 노트(이하 "앱")는 식단·물·운동·체성분 기록을 돕는 개인 프로젝트 앱입니다. 앱은 기록 기능을 제공하는 데 꼭 필요한 정보만 받고, 광고나 판매 목적으로 개인정보를 쓰지 않습니다.

1. 수집하는 정보

로그인 정보카카오 또는 Google 로그인 시 제공되는 계정 고유 식별자, 닉네임(이름), 이메일(동의한 경우), 프로필 이미지 주소(동의한 경우)
직접 입력한 정보닉네임, 키, 나이, 성별, 목표, 체중·골격근량·체지방률 기록, 먹은 음식과 영양 정보, 물 섭취량, 운동 기록
알림 정보알림을 켠 경우 기기의 푸시 구독 정보와 알림 시간 설정, 시간대
사진음식 사진이나 인바디 결과지 사진은 영양 정보를 계산하는 순간에만 쓰이며, 앱 서버에 저장하지 않습니다

2. 이용 목적

  • 로그인한 사용자를 구분하고, 기록을 여러 기기에서 이어서 볼 수 있게 저장
  • 하루 칼로리·단백질·물 목표 계산과 운동 추천
  • 사진이나 글로 음식·체성분 정보를 계산 (AI 분석)
  • 사용자가 켠 경우 물·식사·운동 알림 발송

3. 처리를 맡기는 곳

앱은 아래 서비스를 이용해 운영되며, 각 서비스는 위 목적 범위에서만 정보를 처리합니다.

Supabase로그인 처리, 기록 저장(데이터베이스)
CloudflareAI 분석 요청 전달, 알림 발송 서버
Anthropic (Claude API)사진·글 기반 영양 정보 계산. 분석할 사진과 글, 계산에 필요한 키·체중·목표만 전달됩니다
카카오, Google소셜 로그인
GitHub Pages앱 화면 제공

4. 보관 기간과 삭제

  • 기록은 사용자가 삭제를 요청하거나 계정을 지울 때까지 보관합니다.
  • 삭제를 원하면 아래 문의처로 요청해 주세요. 확인 후 계정과 모든 기록을 지체 없이 삭제합니다.
  • 앱의 설정 → 계정 · 백업 → 기록 내보내기로 언제든 내 기록을 파일로 받을 수 있습니다.
  • '로그인 없이 이 폰에만 저장하기'를 쓰면 기록은 그 기기의 브라우저에만 남고 서버로 보내지지 않습니다.

5. 안전하게 지키는 방법

  • 모든 통신은 암호화(HTTPS)됩니다.
  • 데이터베이스 접근 규칙으로 각 사용자는 자기 기록만 읽고 쓸 수 있습니다.
  • 서버 열쇠(API 키)는 앱 화면에 들어 있지 않고 서버에만 보관합니다.

6. 이용자의 권리

이용자는 언제든 자기 정보의 열람·수정·삭제·처리 정지를 요청할 수 있습니다. 프로필 정보는 앱의 설정 화면에서 직접 고칠 수 있습니다.
